🧩 Marvel Snap Collection Auto-Sync

Extension นี้อ่านไฟล์คอลเลกชันที่เกม Marvel Snap เขียนไว้ในเครื่องคุณเองเท่านั้น ไม่มีการส่งข้อมูลไปที่ไหนทั้งนั้น (ดูโค้ดได้เต็มๆ ใน repo — ไฟล์นี้เล็กมาก อ่านเองได้)

ดูได้จาก path โฟลเดอร์ผู้ใช้ของคุณ ปกติคือ C:\Users\<username>\...

อย่าลืมเปิด "Allow access to file URLs" ให้ extension นี้ด้วย — ไปที่ chrome://extensions → คลิก "Details" ที่ extension นี้ → เปิด toggle นั้น
